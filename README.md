# 我的技术博客

一个纯 **HTML5 + CSS + JavaScript** 实现的个人技术博客，零依赖、零构建，双击即可运行。

## 目录结构

```
├── index.html        # 首页：文章列表 + 搜索 + 标签筛选
├── post.html         # 文章详情页（通过 ?id= 参数渲染）
├── css/
│   └── style.css     # 全部样式（含明暗主题）
└── js/
    ├── posts.js      # 文章数据源（新增文章改这里）
    └── main.js       # 渲染、筛选、主题切换逻辑
```

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

也可以用任意静态服务器（避免个别浏览器对 `file://` 的限制）：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

## 如何新增一篇文章

编辑 `js/posts.js`，在 `posts` 数组里追加一个对象：

```js
{
  id: 'my-new-post',              // 唯一标识，用于 URL
  title: '文章标题',
  date: '2026-10-18',
  tags: ['前端', '随笔'],          // 用于标签筛选
  excerpt: '一句话摘要（显示在列表里）',
  content: `
    <p>正文直接写 HTML 即可。</p>
    <h2>小标题</h2>
    <pre><code>代码块里的 &lt; &gt; 记得转义</code></pre>
  `
}
```

## 特性

- ✅ 文章列表 / 详情两页，`?id=` 路由
- ✅ 关键词搜索 + 标签筛选（可叠加）
- ✅ 明 / 暗主题切换，跟随系统偏好并记忆
- ✅ 响应式排版，手机端友好
- ✅ 阅读时长自动估算
